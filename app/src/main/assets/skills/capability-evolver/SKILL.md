# Capability Evolver

## 功能
1. **能力评估**：评估当前 Agent 在处理任务中的能力短板。
2. **反思循环**：基于失败/不足生成改进建议。
3. **能力增强**：生成新的 skill 或规则以补齐短板。
4. **迭代验证**：验证改进效果并沉淀经验。

## 使用步骤
1. 分析用户请求中 Agent 表现不足的环节。
2. 生成具体、可执行的改进方案。
3. 将改进方案以 skill 或指令形式沉淀。

## 注意事项
- 需要联网模型能力支撑反思。
- 改进建议应具体可落地，避免空泛。
