# Skill Creator

## 功能
1. **规范理解**：掌握 SKILL.md（YAML frontmatter + Markdown 指令）标准结构。
2. **skill 编写**：为需求编写结构清晰的 skill。
3. **结构组织**：合理组织 scripts/、references/、assets/ 目录。

## 使用步骤
1. 明确用户想创建的新技能目标。
2. 编写 SKILL.md，frontmatter 含 name + description。
3. 按需补充 scripts 与引用资源。

## 注意事项
- 纯本地指令型 skill，可直接执行。
- 遵循通用 skill 规范，description 要清晰可路由。
