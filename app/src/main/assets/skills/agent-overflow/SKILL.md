# Agent Overflow

## 功能
1. **记忆共享**：多 Agent 之间共享经验与知识。
2. **协作网络**：将任务拆解并分发到不同 Agent 协作完成。
3. **集体记忆**：沉淀团队级知识库。

## 使用步骤
1. 判断任务是否需要多 Agent 协作。
2. 拆解任务为可并行/串行子任务。
3. 汇总各 Agent 结果形成统一输出。

## 注意事项
- 涉及分布式 Agent 网络，需网络连接。
