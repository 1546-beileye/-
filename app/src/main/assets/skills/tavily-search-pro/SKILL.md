# Tavily Search Pro

## 功能
提供以下核心模式：
1. **Search（通用搜索）**：基础/高级深度，返回 LLM 合成答案、原始页面、图片链接，支持时间过滤、域名白名单/黑名单、国家地区加权。
2. **News/Finance（垂直搜索）**：面向新闻与财经场景优化。
3. **Extract（内容提取）**：从 URL 提取可读内容，支持 Markdown/Text 输出。
4. **Crawl（网站爬取）**：从根 URL 递归抓取，支持路径包含/排除规则、深度限制。
5. **Map（站点地图）**：发现网站全部 URL 结构。
6. **Research（深度研究）**：生成带引用来源的结构化研究报告。

## 使用步骤
1. 确认用户意图属于哪种搜索模式。
2. 提取搜索关键词、URL、过滤条件等参数。
3. 明确告知用户结果来源为 Tavily 搜索 API。
4. 对研究类请求，输出带引用的结构化报告。

## 注意事项
- 需要 Tavily API Key。
- 高级/研究模式消耗积分较多，高频使用成本较高。
- 完全依赖 Tavily 服务端，无离线能力。
